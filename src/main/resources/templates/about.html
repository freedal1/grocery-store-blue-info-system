Опыт работы с технологиями проекта

В рамках разработки проекта автор получил практический опыт создания веб‑приложения на платформе Java 17 с использованием Spring Boot 3.2, а также модулей Spring Security и Spring Data JPA с Hibernate для доступа к данным.

При реализации пользовательского интерфейса были использованы шаблоны Thymeleaf и фреймворк Bootstrap 5, что позволило создать современный адаптивный дизайн. Для хранения данных применялись СУБД H2 и PostgreSQL, а управление зависимостями и сборкой проекта выполнялось с помощью Maven.

Проект позволил закрепить навыки проектирования архитектуры многослойного приложения, настройки безопасности, работы с реляционными базами данных и построения удобного интерфейса для различных ролей пользователей информационной системы продуктового магазина.
